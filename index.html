Using the hub

How this works

What is in here

Two collections. Okanagan College holds our own plans, assessments and datasets. They are catalogued here and held in SharePoint, not copied to a public repository. Peer Institutions holds what BC post-secondary institutions and sector bodies have already published, gathered so nobody has to find the same document twice.

Every record is tagged to the four focus areas and thirteen impact areas from the plan framework, so a filter here matches the language of the plan itself.

Opening a document

  1. Click any row to open the detail panel. It carries the summary, the reuse note, the source and the classification.
  2. Open document loads the library copy where one is held. It opens in your browser's PDF viewer, so use the viewer's own download control to save it.
  3. Original source always goes to the publisher. Use that link when citing anything externally.
  4. Restricted records carry no link by design. Request them from the SustainOC team.

Ground rules

Cite the source, not the hub. Reference the original publisher and the date the document was retrieved. Every record carries both.

Check the date. Peer plans get superseded. A superseded target quoted in a board paper is worse than no target.

Treat this as internal. These are public documents held for internal reference and benchmarking. The hub itself is not published or indexed.

For automated use

The catalogue is a plain data file, not just this page. Point a tool or an assistant at catalogue.json in this repository to get every record with its metadata and a direct link, then fetch only the documents that matter. catalogue.csv holds the same content for Excel.
